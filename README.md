# Agentic Social Media

A Markdown-first editorial operating system for one verified idea -> zero to three platform-native publications.

**Priority:** LinkedIn -> X -> personal blog. Each platform independently decides **PUBLISH / ADAPT / SKIP**. An idea does not have to appear on all three.

Start with [AGENTS.md](AGENTS.md), then [PLAYBOOK.md](PLAYBOOK.md). Specific skills live in `skills/`; reusable forms in `templates/`; policy and research in `research/`.

## Philosophy
* Evidence before writing; reader payoff before background.
* Original engineering experience, product decisions and commercially grounded insights over recycled AI news.
* Natural voice, no synthetic hooks or engagement bait.
* No invented results, collaborators, metrics, endorsements or citations.
* Publishing is manual and requires explicit approval; generated drafts are not publications.

**Status:** bootstrap. Full framework is proposed in a reviewable branch/PR.
