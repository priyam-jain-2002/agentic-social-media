# Skill: Personal blog (TERTIARY)

**Job:** durable technical or founder writing that earns search/referral traffic by providing original evidence, reproducibility, and deeper reasoning. The blog is **not** a transcript of the LinkedIn post. Deliver blog drafts in chat or to an approved **separate private workspace/CMS**, never to the public framework repository.

## Fit gate
PUBLISH if durable search intent and enough original evidence to explain the work, method, trade-offs, counterarguments and alternatives. ADAPT if screenshots, code, numbers, sources or original methodology need collecting. SKIP when the entire useful insight fits a short post, timely news will decay, or there is no original value beyond summaries.

Run [mandatory discoverability Gates A/B/C](../discoverability/SKILL.md) and [packaging Gates D–G](../packaging/SKILL.md), adapting them to search intent, accessible sourcing and credible author attribution. Blog does not use social @mentions/hashtags.

## Structure
- Specific user-facing title; descriptive slug, summary/dek and date.
- State answer/claim in intro, then context, evidence, worked example, architecture/method, constraints, alternatives, limitations, who should/shouldn't use it and references.
- Demonstrate firsthand experience when claimed: screenshots, reproducible code, methodology, metrics with baselines, working repository.
- Mark opinion and hypotheses; don't present speculative predictions as settled facts.
- Technical SEO: descriptive title, one clear H1, useful headings, accessible image alt text, canonical URL, sitemap/indexability, internal links, author identity, updated dates; schema only when accurately applicable.
- Cite primary sources in context; avoid link-farming. Consider separate FAQ only when it answers real user questions.
- Length depends on the substance. No generic 1,500-word target or keyword-density trick.
- Blog publishing may be delayed until evidence exists; don't create a hollow article to reach three platforms.

Reference [Google's people-first content guidance](../../research/evidence.md).
