# Skill: visual and media direction

**Decision gate first:** NONE / real artifact / photo / benchmark chart / explanatory diagram / illustrative graphic. No generated visual merely because social content is being created.

Priority: (1) real product/demo screenshot; (2) real data chart with source; (3) accurate architecture diagram; (4) original illustration when the concept cannot be shown otherwise. Don't replace evidence with a seductive fictional UI.

## Required visual brief template
```
Platform + placement:
One-sentence audience takeaway:
Type (evidence, instructional, conceptual):
Source assets and permission to share:
Exact facts and numbers to reproduce:
Key visual hierarchy (headline 6-10 words max, primary subject, optional support):
Composition and crop: LinkedIn mobile-first; X crop-safe; blog responsive
Contrast/accessibility + alt text:
Allowed illustration vs source evidence; provenance/disclosure:
Banned content: unsourced metrics, fake logos/screenshots, fake dashboards, licensed data, decorative text walls
Acceptance test: understandable in 2 seconds at phone size; legible at reduced width; claims match text
```

## Generation instruction for a conceptual graphic
'Produce an original, clean, high-contrast technical editorial graphic. The single visual claim is: [CLAIM]. Audience: [AUDIENCE]. Show [ONLY KEY OBJECTS AND THEIR TRUE RELATIONSHIP]. Use a mobile-first visual hierarchy with short copy (headline <=10 words, labels <=4 words) and generous negative space. Match brand/platform context. No fake metrics, screenshots, citations, company affiliation, trademark misuse, dashboard artifacts or invented performance. This is a conceptual illustration, not proof. Output also a factual alt-text description and visual-claim check.'

## Validation
- If user requests image creation, use the available image tool, then visually inspect text and factual correctness; regenerate/correct typos.
- Don't claim compatibility with exact brand assets unless the assets were supplied/verified.
- If visual cannot simplify without misleading, publish as text-only.
- Blog graphs need data provenance and explanatory captions. Company or athlete images require rights review.
