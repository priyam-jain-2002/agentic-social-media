# Packaging skill — early payoff, proof, natural voice

**Purpose:** prevent clear but tedious posts that reveal the valuable point too late.

## Common failure modes (editorial checks, not causal ranking claims)
- Lengthy generic background delays the actual insight, result or decision.
- Speculative commentary offers no experiment, sourced counterargument or artifact to inspect.
- A decorative infographic stands in for original evidence or repeats an already long caption.
- A post has no specific reader payoff beyond the author reporting an opinion.
- Observational post-performance data alone cannot establish causality; investigate alternative explanations.

## Gate D — Scrolling/preview test (PASS / REWRITE)
Show only the first ~200 characters (editorial approximation, not a LinkedIn UI claim) and the thumbnail if any. Can a new reader answer: `Who is this for?` `What is the useful or surprising point?` `Why continue?` If not, REWRITE the hook.

## Gate E — Payoff and density (PASS / REWRITE)
- Main insight appears in opening third, with first concrete proof promptly afterward.
- Cut context that merely prepares the reader; move source attribution after the point when appropriate.
- One main claim. Every paragraph contributes evidence, constraint, implication or genuinely new information.
- Default LinkedIn test range 80–140 words (not algorithmic optimum); expand only for useful additional evidence.
- Normal readable paragraphs; don't use robotic one-line rhythm.
- Last paragraph resolves the opening promise; optional question must invite specific expert discussion, not fake engagement.

## Gate F — Proof/visual coherence (PASS / HOLD)
- Real build → real screenshot/demo/repo. Experiment → comparison and method. News analysis → current primary/credible sources + specific mechanism + counterargument. Team result → score and accurately credited members.
- A hypothetical diagram is an illustration, **not proof**. Mark hypotheses as such.
- Visual thumbnail conveys one truthful idea in 2–3 seconds on mobile. A text wall or unverified graphic fails.
- Use no visual when the actual evidence is clearer in prose.
- **HOLD** when a central unverified claim cannot be removed without changing the thesis.

## Gate G — Human voice (PASS / REWRITE)
Read aloud. Would this author naturally say it? Reject formulaic 'it's not X, it's Y' repetition, generic 'thought leadership', forced rhetorical suspense, motivational filler, keyword stuffing and praise of one's own work.

## Output
`D=... E=... F=... G=...; most important change: ...; recommended verdict: READY|REVISE|HOLD|SKIP`.

Gates D–G supplement, and never override, the repository's hard truth, sensitivity and authenticity gates.
