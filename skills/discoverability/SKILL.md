# Discoverability, taxonomy, hashtags and mentions

**Purpose:** classify the idea for the right readers, then decide whether specific public metadata or tags materially help. A list of hashtags or @names is not an editorial strategy.

## Gate A — Taxonomy and audience fit (PASS / REVISE / SKIP)
Before writing, record:
- **One primary pillar:** AI-SYSTEMS / PRODUCT / FOUNDER / ENGINEERING / MARKET-THESIS / OPEN-SOURCE.
- **0–2 secondary themes:** BUILD / CROSS-DISCIPLINE / REFERENCE / a precise recurring subject.
- **One primary reader:** e.g. frontend engineer, AI infrastructure engineer, technical founder, distributor/operator.
- **One reader job:** learn a method, inspect proof, assess a trade-off, understand a change, evaluate a market, or debate an open technical question.
- **2–5 natural keywords and entities:** specific technical terms, projects, products, companies and use cases; use where natural in the opening, body and alt text rather than stuffing.
- **Evidence type:** artifact / measured experiment / firsthand observation / primary docs / attributed news / hypothesis.
- **Uniqueness:** what this author adds beyond a news repost, and what the audience will have learned.
- **Platform fit:** LinkedIn / X / blog each gets its own audience reason; SKIP is valid.

**PASS** if reader, problem, perspective, evidence and platform all align. **REVISE** when the audience or technical vocabulary is unclear. **SKIP** when a topic exists only for trends, prestige or a posting quota.

## Gate B — Hashtags / search terminology (PASS / REMOVE / VERIFY)
1. Start with **no hashtags**. Add a tag only if it labels a real subject, community or event that is useful to readers; justify its presence individually.
2. Make sure natural-language keywords communicate the topic **without hashtags**. No vague #AI #Innovation #Success chains or irrelevant trending tags.
3. **LinkedIn:** default 0; optionally 1–3 specific tags for organization/discovery, never as a feed-distribution trick. In LinkedIn's December 2025 Feed Q&A, an executive explicitly stated hashtags do not impact distribution. Do not promise a reach boost.
4. **X:** default 0; if needed no more than two targeted tags (aligned with X Help). Don't chase unrelated trends.
5. **Blog:** no social hashtags. Choose a maintained topic category, optional precise tags, and meaningful query/title/H1/slug/internal links. SEO metadata must be accurate and usable.
6. **PASS** if every public tag has a documented rationale and natural terms are present. **REMOVE** unjustified tags. **VERIFY** event/campaign spellings, exact technical terms and current topical relevance.
7. Do not conflate *internal taxonomy tags* with the *public hashtag list*.

## Gate C — People, brand and organization mentions (PASS / REMOVE / HOLD)
Each potential tag must have a role:
- Direct collaborator or contributor being credited for actual work.
- Original source or subject directly analyzed and accurately attributed.
- Relevant organization that ran/hosted the real event, with precise wording that does not imply sponsorship.
- Exceptionally, a person invited for a **specific genuine insight**, not mass tagging for their followers.

For EACH tag record: **name/handle**, contribution or source role, **verified account URL**, exact placement, affiliation claim check, and whether collaborator consent/co-author approval is needed.
- Never invent exact handles; text `@Name` is a placeholder until selected/confirmed in the platform interface.
- Check spelling of names, actual projects and organizer names.
- Prefer co-authorship only for genuine shared work with collaborators' agreement. LinkedIn account settings and feature availability may affect tagging/collaboration; don't assume an invitation was sent.
- **LinkedIn:** no engagement-bait tags of celebrity, employer, or product page. Tag genuine collaborators when credit materially helps. No forced number of tags.
- **X:** mention relevant handle only when it adds source attribution or participation; otherwise text reference/link can suffice. Avoid unwanted notifications.
- **Blog:** use linked attribution in prose, not @mention syntax. Avoid listing people's identities when not needed or authorized.
- **PASS** when every name is accurate, necessary and not misleading. **REMOVE** unnecessary tags. **HOLD** if identity/affiliation is unverified or coauthor consent is missing.

## Output in every content record
```
Primary / secondary taxonomy:
Reader persona / problem / intended takeaway:
Keywords and entities:
LinkedIn hashtags: none | exact tags + rationale
LinkedIn mentions: none | verified profile/page URL + role + placement + consent
X hashtags: none | exact tags + rationale
X handles: none | verified URLs + rationale
Blog category/tags/search intent: ... | SKIP/HOLD
Gate A: PASS|REVISE|SKIP
Gate B: PASS|REMOVE|VERIFY
Gate C: PASS|REMOVE|HOLD
```
