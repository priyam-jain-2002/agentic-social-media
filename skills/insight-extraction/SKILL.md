# Skill: Firsthand insight extraction

**Trigger:** User shares a project milestone, bug, technical decision, demo, customer interaction, open-source contribution, or learning. Can be captured between weekly research scans.

## No-effort intake
Ask for at most one missing critical fact at a time if needed; otherwise return a rough [insight card](../../templates/insight-card.md) **in chat or an approved private destination** without forcing a content draft. Accept a sentence, commit link, screenshot, voice-note summary or incident description.

Extract:
1. **What happened:** exact event; observed vs inferred; timeline.
2. **Initial expectation vs result:** why interesting; avoid dramatic fabrication.
3. **Decision/trade-off:** why approach chosen and alternatives rejected.
4. **Who can use it:** precise engineer, founder or operator; reader value independent of the author's status.
5. **Evidence and permissions:** public repo, screenshot, metrics with baseline, demonstration; whether employer/customer/project material is approved for public reuse.
6. **One teachable insight:** can a stranger apply or falsify it?
7. **Proof-to-publication gap:** a 15–60 minute artifact/mini-experiment, if needed.
8. **Originality/duplicate:** prior posts and thesis overlap.
9. **Time to tell:** evergreen / this week / under embargo.

**Capture gate:** If noteworthy but not proven, store as UNVERIFIED / HOLD. Don't translate a private engineering report into public content without explicit approval.

**Handling confidentiality:** This repository is public. Never commit nonpublic employer information, private customer details, proprietary code, raw screenshots, internal benchmarks or sensitive financials. Store the detailed card only outside this repo in a private workspace; this public framework repository accepts **no** generated idea cards, even sanitized ones. Never silently sync a connected repo.

**Output:** one card with first-hand provenance, one compelling possible statement (not marketing copy), one counterargument, needed evidence, and route suggestions for LinkedIn/X/blog.
