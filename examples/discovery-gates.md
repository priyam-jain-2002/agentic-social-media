# Example prepublication gate: headless storefront

**Reader:** frontend engineers considering an e-commerce build.
**Primary pillar:** PRODUCT; secondary BUILD.
**Search terms:** custom storefront, headless commerce, Wix Headless, Shopify, managed commerce APIs.

| Gate | Decision | Reason |
| --- | --- | --- |
| A Taxonomy / reader fit | PASS | One clear reader and actionable engineering distinction |
| B Hashtags/search | PASS: 0 LinkedIn hashtags; optional #HeadlessCommerce only if useful | Readers can understand/search exact terms without a hashtag |
| C People/org mentions | PASS: none | Merely using Wix or Shopify does not justify tagging employees or brands for reach |
| D Hook | PASS after showing capability up front | Lead with 'custom storefront without implementing the catalog/order backend' |
| E Early payoff | PASS if explanation follows immediately | Avoid paragraphs about why e-commerce is exciting |
| F Proof/media | HOLD until authentic screenshot is available for a firsthand-implementation claim | Mockup can't establish an actual live build |
| G Voice | PASS after natural read-aloud edit | No forced CTA, buzzwords or artificial suspense |

**LinkedIn:** ADAPT/HOLD until screenshot; then show real feature and honest backend boundary.
**X:** PUBLISH as a factual general observation, with no fabricated first-person implementation claims and no handles.
**Blog:** HOLD until architecture walkthrough, exact integration constraints and deployment proof exist.

**General rule:** if a post mentions Nvidia/CUDA, that alone does not justify tagging Nvidia. If a hackathon has actual team authors, verify names/consent and use genuine collaboration credit, not reach-hacking.
